# Warm Glass Tableで進める透過・屈折のロードマップ

木目のテーブルに置いたガラスについて、ガラス越しの像と、テーブルに届く光の両方を評価する。
4点を並べる完成シーンと、光源やガラスを1つずつ切り替える検証プリセットを使い分ける。

現在のシーンは薄肉・厚肉の中空グラス、薄い板、厚い板、暖色の点光源3灯で構成される。
厚い板は体積屈折を使い、グラスと薄い板は薄膜透過を使う。
Native PTはガラス越しの像を描けるが、直射光の影レイは遮蔽の有無だけを返す。
このため、テーブル上の色付き透過影と光が集まる模様は別途実装する。
[現行シーン](../Assets/Scenes/WarmGlassTable/README.md) · [影レイの実装](../Shaders/shaders_PathTracing.hlsl)

| 段階 | 変更 | 難易度 |

| 0 | 比較条件を固定し、影と屈折像を分けて測る | 低 |
| 1 | 薄い板を通る直射光に透過率と色を反映 | 中 |
| 2 | 厚い平板で入射・出射・距離吸収を直射光に反映 | 高 |
| 3 | 中空グラスの内外境界を体積屈折で扱う | 高 |
| 4 | 曲面が集めた光を木目のテーブルに描く | 最高 |
| 5 | 3灯の完成シーンで画質・性能・RRを評価 | 中〜高 |

## 0. 比較条件を固定する

- カメラ、露出、シード、バウンス数を固定する。3灯の完成構図と、暖色の主光源だけを残す測定用設定を用意する。
- 薄板のみ、厚板のみ、グラスのみを同じテーブルで撮る。無遮蔽、同じ形状の不透明材、透過材の対照を揃える。
- テーブルの影領域、輪郭をまたぐ帯、ガラス越しの背景を別々に記録する。光の量はトーンマップ前の線形RGBで比較し、木目の見え方は表示画像で確認する。
- 現行Nativeの収束画像は、既存の見え方と影の基準にする。追加する光輸送は、簡単な解析ケースか独立した参照で検証する。

### エッジの反射を切り分ける

薄膜と体積屈折のシェーダーは、入射角に応じて反射をサンプルする。現在の3灯は点光源で、テーブルを照らせても、ガラスの縁に映る幅のある光源像を作りにくい。板は面取りなしの箱なので、角の法線が切り替わる幅もない。

- まず反射用の細長い発光面を1枚加え、同じ視点で有無を比較する。Nativeの収束画像でグラスの口縁、側面、板の角に映る光の位置と幅を確認する。
- 光源像が確認できたら、板の面取りとグラスの口縁法線を個別に調整する。薄い板と厚い板の厚みは揃えず、同じ光源条件で比較する。
- Nativeでエッジが出てから、同じ条件のRRで反射の細さや強さが保たれるか確認する。テーブル上の透過影・集光の評価とは別の領域で判定する。

## 1. 薄い板の透過影

直射光の可視性にRGB透過率を返す経路を追加する。初回は薄膜モデルで扱える直進透過に限定する。
薄膜の透過率、色、角度依存の反射分を既存の薄膜モデルと整合させ、途中に不透明面があれば遮蔽する。
層の重なりは少数の上限付きで扱い、板メッシュの表裏を二重に数えることを避ける。
最初の試験は一枚面の板とし、現在の薄い箱型メッシュの扱いを明示してから完成シーンへ反映する。

**合格条件**　無色の板の下で木目が見え、着色板では透過光に色が付く。不透明対照は遮蔽し、透過率1・IOR 1では無遮蔽に近づく。影レイのヒット上限を超える入力は診断できる。既存の不透明シーンで明暗と処理時間を確認する。

## 2. 厚い平板の屈折と吸収

1つの滑らかな閉じた平板を対象に、テーブルの受光点と光源を結ぶ屈折経路を求める。
平行な入射面・出射面で光が横にずれるので、元の直線上で透過率だけを変える方法とは別の接続として実装する。
屈折経路に沿って遮蔽を確認し、両界面の透過と内部距離による吸収を評価する。
点光源1灯から始め、経路の重みとエネルギーを独立した平板モデルで照合する。
全反射や経路が見つからない条件も診断する。

**合格条件**　IOR 1でずれが消え、IOR 1.5で境界位置が参照と一致する。吸収を入れると長い経路ほど暗くなり、NaNや過剰な明るさが出ない。

## 3. 中空グラスの体積モデル

薄肉・厚肉のグラスをそれぞれ、底・外壁・口縁・内壁がつながった境界として検証する。
空気とガラスを出入りする順番、内面の法線、壁と底の厚み、全反射を確認する。
現行のVolumeは閉じた凸形状1個を前提にするため、まずグラス1個の隔離シーンで中空境界に対応する。
複数の独立したVolumeを順に通る経路が正しく扱えることを確認してから、グラス2個と厚い板を完成シーンで組み合わせる。

**合格条件**　薄肉・厚肉で背景の曲がり方と底越しの像が変わり、ガラス内部の吸収距離が幾何と一致する。口や底で境界の取り違えが起きない。

## 4. コースティクス

曲面のグラスを通った光がテーブルに集中する経路を、単一の光源と受光面で検証する。
最初に光源からレイを出す参照実装を作り、受光位置とエネルギー分布を記録する。
この参照を使い、実時間側で光源側サンプリングや屈折経路の接続を比較する。
光源サイズを変えて模様の広がりを評価し、粗い屈折ではボケの幅とノイズの増え方も測る。
既存の直射寄与との二重計上を防ぎ、サンプル数や光源数を変えたときのGPUコストを測る。
[光源とカメラの両側から経路を作る方法](https://pbr-book.org/3ed-2018/Light_Transport_III_Bidirectional_Methods/Bidirectional_Path_Tracing)

**合格条件**　光源やグラスを動かすと集光位置も参照に沿って動く。テーブル上の積分エネルギーが参照と整合し、模様のちらつきが評価できる。

## 5. 完成シーンと再構成

暖色3灯を戻し、木目の上で無色・着色の透過影、厚い板のずれ、グラスの集光を並べて確認する。
まずNativeで物理的な変化を判定し、その後にRRでノイズ低減と像の保持を比較する。
静止、カメラ移動、ガラス移動を分け、テーブル上で動く光の模様の残像も見る。
RRの新規出力・入力拒否・履歴リセットを記録し、GPU時間と合わせて対応範囲を確定する。

最初のPRは段階0〜1。暖色の主光源1灯と薄板1枚で透過影を実証し、完成シーンの木目でも見え方を確認する。
段階2以降は光輸送・境界・再構成の変更を分けて評価する。
