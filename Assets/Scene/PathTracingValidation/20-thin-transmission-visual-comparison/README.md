# 薄膜透過の目視比較

左から、板なし／無色透過／青色透過／不透明な青い板。
各枠の背後に同じ白黒格子、オレンジの球・箱を置く。
板の有無は色面ではなく、背景と物体が見えるかで確認する。

- 1〜3で球・箱・格子が見える。4では板に遮られる。
- 無色はIOR=1.5の表面反射を持ち、板なしとの完全同値は要求しない。
- 青色の透過は背後の物体・模様を着色する。
- 板はz=0、物体はz=1.4、格子はz=3。カメラ移動で奥行きを確認できる。
- カメラは透視投影なので、各セルの映り込みや物体輪郭の厳密な画素一致は要求しない。
- RGBAを変更し、Undo・保存復元・PT蓄積リセットを確認する。

Native PT限定。色付き影、屈折歪み、厚み、NRD透過は未対応。
定量的な正しさの評価は既存の薄膜結合テストを使う。
